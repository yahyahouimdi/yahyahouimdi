## 🚀 Featured Projects

### 🛰️ Remote Sensing Image Captioning

**AI Research · Computer Vision · Vision-Language Models**

Research project focused on generating natural-language descriptions from satellite imagery using **SwinV2 and Transformer-based architectures**.

* Investigating transformer-based approaches for remote sensing image captioning
* Reproducing and extending an existing research baseline
* Designed and evaluated modifications to the feature-processing pipeline
* Achieved a **+136.7% CIDEr improvement** over the reproduced baseline
* Working with remote sensing datasets including **RSICD, UCM-Captions and Sydney-Captions**

[→ View project](https://github.com/yahyahouimdi/RSIC_remote_sensing_image_captioning)

### 🏥 Patient Monitoring with Agentic AI

**Applied AI · Agentic Systems · Distributed Systems**

An intelligent patient-monitoring architecture combining **Apache Kafka, rule-based agents, and reasoning-based AI agents** for real-time emergency detection.

* Event-driven architecture built around Apache Kafka
